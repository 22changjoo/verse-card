# 말씀카드

심방 전후나 절기에 성도님께 보낼 **말씀 카드 이미지**를 휴대폰에서 빠르게 만들어 카카오톡으로 보내거나 인쇄하는 웹앱입니다.
서버 없이 브라우저 안에서만 동작하는 정적 웹앱(HTML + CSS + JavaScript)입니다.

## 쓰는 방법

1. **카드 유형 선택**: 심방 카드 / 절기 인사 카드
2. **입력**: 받는 분, 인사말, 말씀 본문, 출처, 보낸 이
   - 심방 카드: "심방 상황"을 고르면 인사말 예시가 나옵니다. 눌러서 넣고 자유롭게 고쳐 쓰세요.
   - 절기 카드: 절기를 고르면 색·장식·제목·인사말 예시가 함께 적용됩니다.
   - 부부처럼 직분이 다른 두 분께는 "+ 함께 받는 분 추가"를 쓰세요.
   - 보낸 이 뒤의 맺음말은 **드림 / 올림 / 표기 안 함 / 직접 입력**에서 고릅니다. (연장자께는 "올림")
3. **디자인**: 템플릿, 크기(정사각/세로/배경화면/엽서), 배경색, 글꼴, 글자 크기, 장식, 교회 로고

### 교회 로고
기본으로 **높은뜻푸른교회 나뭇잎 로고**(`assets/logo/leaf.png`)가 카드 아래쪽 보낸 이 위에 들어갑니다. "로고 표시"를 끄면 빠집니다.
다른 로고를 쓰려면 "다른 로고 올리기"로 파일을 올리세요. 앱이 바깥 여백을 잘라 내고 로고 모양을 찾아 둡니다. (올린 로고는 그 기기에만 저장됩니다.)
- **로고 색**: *자동*(기본: 밝은 배경은 로고 원래 색, 어두운 배경은 카드에 어울리는 한 가지 색) / 테마 단색 / 원본 색 / 흰색 / 검정
- **로고 크기**: 작게 / 보통 / 크게
- 배경이 투명한 PNG가 가장 깔끔합니다. 흰 배경이 있는 JPG도 배경을 지우고 모양만 씁니다.
- 기본 로고 파일을 바꾸려면 `assets/logo/leaf.png`를 교체하고 `sw.js`의 `VERSION`을 올리세요.

### 말씀이 길 때
글자를 줄이기 전에 줄간격을 먼저 좁혀(1.75 → 최소 1.4) 한 장에 담습니다. 그래도 안 들어가면 글자를 줄이고, 가장 작은 크기로도 안 들어가면 절 단위 나누기를 권합니다.
4. **보내기**: 공유하기(카카오톡 등) / 이미지 저장 / 인쇄(엽서 100×148mm)

### 홈 화면에 추가하기 (앱처럼 쓰기)
- **iPhone (Safari)**: 공유 버튼 → "홈 화면에 추가"
- **Android (Chrome)**: 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치"

한 번 열어 두면 인터넷이 없어도 열립니다.

> 카카오톡 등으로 바로 공유하는 기능은 **HTTPS 주소**(예: GitHub Pages)에서만 동작합니다.
> 그 외의 주소에서는 "이미지 저장"으로 사진첩에 저장한 뒤 보내세요.

### 긴 말씀 나누기
말씀이 길어 글자가 너무 작아지면 "절 단위로 나누기" 버튼이 나옵니다.
절은 **줄바꿈으로 구분**하거나 본문 앞에서부터 **절 번호(1 2 3 …)** 를 넣어 두면 인식합니다.
절 중간에서는 절대 나누지 않고, 출처는 마지막 장에만 표시됩니다.

## 성경 본문과 저작권

- **이 앱은 성경 본문을 제공하지 않습니다.** `data/verses.json`에는 장절 참조와 주제만 있고 본문(`text`)은 모두 비어 있습니다.
- 사용하실 본문은 **직접 입력**해 주세요. (`말씀 라이브러리`에서 입력해 두면 카드 화면에서 불러올 수 있습니다.)
- 개역개정·새번역은 대한성서공회 저작물입니다. 사용 범위는 해당 기관의 안내를 확인해 주세요.
- 카드에 쓰인 장식 도형(새싹, 십자가, 해돋이, 매화 등)은 이 프로젝트용으로 직접 만든 것입니다.

## 개인정보

- 받는 분 이름, 인사말, 말씀, 설정, 로고, 라이브러리는 **이 기기의 브라우저(localStorage)에만** 저장됩니다. 서버로 전송하지 않습니다.
- "최근 받는 분"은 카드를 실제로 저장·공유·인쇄했을 때만 기록되며(최대 10명), 화면 맨 아래 **"기록 지우기"** 로 지울 수 있습니다. "모두 초기화"는 설정·로고·라이브러리까지 지웁니다.
- 외부 요청은 **글꼴을 받아 오는 Google Fonts뿐**이며, 입력한 내용은 담기지 않습니다. 한 번 받은 글꼴은 이 기기에 저장해 두고 이후 오프라인에서도 씁니다.

## 말씀 라이브러리

`library.html`에서 주제별 장절 목록에 본문을 직접 입력합니다. (자동 저장)
목록에 없는 말씀은 "직접 추가"로 넣을 수 있습니다.
**중복 정리**: 같은 말씀이 여러 번 들어 있으면 한 번에 정리합니다. 표기가 달라도("요 3:16" / "요한복음 3:16" / "시편 23편 1절") 같은 말씀으로 봅니다.
기본 목록에 있는 말씀은 지우지 않고, 직접 추가한 중복만 정리합니다. 본문이 서로 다르면 지우지 않고 남겨 두며, 정리 후에는 "정리 되돌리기"로 이전 상태로 돌아갈 수 있습니다.
이미 목록에 있는 말씀을 "직접 추가"하려고 하면 새로 만들지 않고 기존 항목을 알려 줍니다.
**파일로 내보내기 / 가져오기**로 휴대폰 ↔ Mac 사이에 옮길 수 있습니다. 브라우저 데이터를 지우면 라이브러리도 사라지니 가끔 내보내기로 백업해 두세요.

## 내용 고치기

| 하고 싶은 일 | 고칠 파일 |
|---|---|
| 인사말 예시 문구 고치기·추가 | `data/greetings.json` |
| 절기 이름·색·제목 | `data/templates.json`의 `seasons` |
| 배경색 팔레트, 글꼴 목록, 크기(비율) | `data/templates.json`의 `palettes`, `fonts`, `sizes` |
| 말씀 장절 목록 | `data/verses.json` (`text`는 비워 두세요) |
| 템플릿 모양(CSS) | `css/templates.css` |
| 템플릿 장식 도형 | `js/render.js`의 `DECOR`, `SEASON_ICON` |

**새 템플릿 추가**: `data/templates.json`의 `templates`에 항목을 넣고, `js/render.js`의 `DECOR`에 장식을 추가한 뒤 `css/templates.css`에 `.tpl-아이디 { … }` 블록을 만듭니다.

> 파일을 고쳐서 배포했는데 이전 화면이 그대로 보이면, `sw.js` 맨 위의 `VERSION` 숫자를 올려 다시 배포하세요. (기존에 설치한 기기의 저장본이 새로 바뀝니다.)

## 파일 구조

```
verse-card/
├── index.html            카드 만들기 화면
├── library.html          말씀 라이브러리
├── manifest.json, sw.js  홈 화면 추가(PWA)·오프라인
├── css/                  app.css(화면) · templates.css(카드) · library.css
├── js/
│   ├── render.js         카드 그리기 (입력 화면과 분리 — 나중에 일괄 생성에도 재사용)
│   ├── split.js          긴 말씀을 절 단위로 나누기
│   ├── export.js         PNG 저장·공유
│   ├── print.js          엽서 인쇄
│   ├── logo.js           로고 여백 자르기·모양 찾기·색 입히기
│   ├── library.js        라이브러리 저장·가져오기
│   ├── storage.js        localStorage
│   ├── app.js            화면 동작
│   └── vendor/modern-screenshot.js   카드를 이미지로 바꾸는 라이브러리(MIT)
├── data/                 templates.json · greetings.json · verses.json
└── assets/icons/         앱 아이콘
```

## 내 컴퓨터에서 실행

빌드가 필요 없습니다. 이 폴더에서 간단한 서버를 켜면 됩니다.

```bash
python3 -m http.server 8765
```

브라우저에서 `http://localhost:8765/` 를 엽니다. (파일을 더블클릭해서 여는 방식은 데이터 파일을 읽지 못해 동작하지 않습니다.)

## 배포 (GitHub Pages)

1. 이 폴더를 GitHub 저장소(`verse-card`)에 올립니다.
2. 저장소 **Settings → Pages → Branch: `main` / 폴더: `/ (root)`** 로 설정합니다.
3. 잠시 뒤 `https://<계정>.github.io/verse-card/` 에서 열립니다.

모든 경로가 상대 경로라서 하위 주소(`/verse-card/`)에서도 그대로 동작합니다.

## 알아둘 점

- **인쇄**는 선택한 크기와 관계없이 항상 엽서(100×148mm)로 만들어집니다. 인쇄 창에서 용지 크기를 확인하세요. 같은 엽서 2장을 A4 가로에 배치하는 옵션도 있습니다.
- 글자 크기는 말씀이 칸에 들어가는 범위에서 자동으로 맞춰집니다. 가장 작은 크기(1080px 기준 34px)로도 안 들어가면 나누기를 권합니다.
- 두 분까지 함께 받는 분으로 지정할 수 있습니다.

## 앞으로 (이번에 구현하지 않음)

송구영신 일괄 제작, 하세나하시조 앱 연동, 심방 기록 연동, 생일·절기 MMS 자동 발송은 `말씀카드_작업지시서.md`의 확장 메모를 참고하세요.
카드 그리기(`js/render.js`)를 입력 화면과 분리해 두어, 나중에 일괄 생성·자동 발송 모듈이 같은 함수를 쓸 수 있습니다.
